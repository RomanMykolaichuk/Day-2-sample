# Day-2-sample

A simple interactive web page introducing **AI Agents**.

The project demonstrates the transition from AI systems that mainly **answer questions** to agentic systems that can **plan, use tools, observe results, and act toward a goal**.

## Features

- Introduction to AI agents
- Agent anatomy and core components
- Agent workflow
- Interactive demo
- Risks and limitations
- Responsive single-page design

## Project structure

```text
Day-2-sample/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run locally

No installation is required.

1. Clone the repository:

```bash
git clone https://github.com/RomanMykolaichuk/Day-2-sample.git
```

2. Open the project folder.
3. Open `index.html` in your browser.

## GitHub Pages

If GitHub Pages is enabled for the `main` branch, the site can be published directly as a static website.

This repository was created as a practical training example for working with:
